This project involves cleaning, transforming and analysing sales data using Power BI.

Data Preparation: Imported the CSV dataset, handled missing values, removed duplicates, standardized date formats and created calculated Profit and Sales columns using Power Query.

Visualizations: Created a regional order distribution pie chart, a top five products column chart and a profit trend line chart.

DAX Calculations: Created the EastRegionOrders calculated table, ProfitCostDifference calculated column and TotalProfit measure.

Conclusion: Demonstrated practical skills in data cleaning, visualization and DAX-based analysis using Power BI.# Intermediate-Assessment-Power-BI
